- option narration
- feedback
- reminders
- replay

- audio caching

Do NOT make this a global replacement for the application's existing TTS.

==================================================
VOICE QUALITY
==================================================

The Story Adventure voice should use Gemini's current supported native audio/TTS capability.

The voice should sound:

- natural
- warm
- expressive
- friendly
- child-friendly
- conversational
- patient
- educational

It should NOT sound like:

- browser SpeechSynthesis
- robotic TTS
- GPS voice
- IVR
- monotone narration

The voice should feel like a friendly narrator guiding an 8-year-old child through the story.

==================================================
STORY SLIDE NARRATION
==================================================

When a Story Adventure slide opens:

1. Stop any previous Story Adventure audio.
2. Load the current slide.
3. Automatically narrate the current slide.
4. Use the existing story content/caption.
5. Use natural pauses and expressive delivery.

Example:

"Riya school se ghar aa rahi hai...

Raste mein use ek chhota sa gaon dikhai deta hai,
jahan kuch bachche khel rahe hain."

Do not invent new story facts.

==================================================
QUESTION SLIDE
==================================================

For the Story Adventure question slide ONLY:

Voice sequence:

1. Explain the situation.
2. Read the question.
3. Read option 1.
4. Pause.
5. Read option 2.
6. Wait for the child.

Example:

"Riya ke saamne ab ek important decision hai...

Kya woh Aman ki madad karegi?

Option one...

Chup chaap aage badh jao.

Option two...

Aman ke liye help bulao.

Ab aapki baari hai."

==================================================
NO ANSWER REMINDERS
==================================================

If the child does not select an option:

Use gentle, varied reminders.

Example:

"Abhi tak koi option select nahi hua hai.
Aapko kaunsa answer sahi lagta hai?"

Another:

"Chalo, Riya ki help karte hain.
Neeche diye gaye options mein se ek choose karo."

Another:

"Ab aapki baari hai.
Kisi ek option par tap karo."

Do NOT repeat the exact same sentence continuously.

Use reasonable intervals.

==================================================
ANSWER SELECTED
==================================================

The moment the child selects an answer:

- immediately stop Story Adventure voice
- cancel Story Adventure reminder timers
- clear Story Adventure audio queue
- process the selected answer

Do NOT allow any reminder to continue after the answer is selected.

==================================================
WRONG ANSWER
==================================================

For a wrong answer:

Use the Story Adventure Gemini voice to explain the existing feedback naturally.

Example:

"Chalo, ek baar phir sochte hain...

Aman ko help ki zaroorat thi.
Aise situation mein kisi trusted adult ya doctor se help lena important hai.

Try Again par tap karke dobara choose karo."

Do not punish or shame the child.

==================================================
CORRECT ANSWER
==================================================

For a correct answer:

Use an encouraging voice.

Example:

"Bahut badhiya!

Aman ke liye help bulana sahi decision tha.
Kisi bachche ko zaroori madad ki zaroorat ho,
toh trusted adult ya doctor se help lena important hai.

Ab Next par tap karke story continue karo."

==================================================
AUDIO MANAGEMENT
==================================================

Story Adventure must have its own isolated audio manager.

It must support:

speak()
stop()
replay()
preload()
isSpeaking()

Only one Story Adventure audio response can play at a time.

When:

- slide changes
- Back clicked
- Next clicked
- answer selected
- Try Again clicked
- Story Adventure closed

Immediately stop Story Adventure audio.

==================================================
AUDIO CACHE
==================================================

Because story content is mostly static, cache the generated Story Adventure audio.

Cache separately for:

- slide narration
- question
- options
- correct feedback
- wrong feedback
- reminders
- completion narration

Do not regenerate the same audio unnecessarily.

Where possible, preload the next Story Adventure slide's audio.

==================================================
PERFORMANCE
==================================================

The Story Adventure voice should start quickly.

Do not make a new Gemini request for every tiny sentence if it can be avoided.

Do not generate audio repeatedly for the same fixed story content.

Do not affect the performance of the rest of the game.

The Story Adventure voice system must remain isolated from the main game's rendering and AI systems.
