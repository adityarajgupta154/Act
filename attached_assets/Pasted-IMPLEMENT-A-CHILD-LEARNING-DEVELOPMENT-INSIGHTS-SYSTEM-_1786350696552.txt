3. LEARNING PATTERN ANALYSIS
==================================================

The AI should analyze patterns over time instead of judging the child from a single answer.

For example:

If the child repeatedly struggles with a particular topic:

"Repeated difficulty observed in Digital Safety questions."

If the child improves:

"Performance improved from 55% to 78% over recent attempts."

If the child needs repeated hints:

"This topic may benefit from additional explanation and practice."

If response time is increasing:

"Recent activities show longer completion times."

Do NOT say:

"You have anxiety."
"You have ADHD."
"You have depression."
"You have a psychological problem."
"You have low intelligence."
"You have a specific mental disorder."

Never make medical, psychological, psychiatric, personality, or intelligence diagnoses.

6. DO NOT ANALYZE SINGLE EVENTS
==================================================

Never generate an insight based on one wrong answer.

Use multiple observations over time.

For example:

Minimum recommended evidence:
- several questions
- multiple attempts
- multiple sessions where possible

If insufficient data exists, say:

"Not enough activity data yet to identify a meaningful learning pattern."

13. PRIVACY & CHILD SAFETY
==================================================

Because this system handles children's data:

- minimize collected data
- do not collect unnecessary personal information
- do not collect real names unless explicitly required and consented
- do not collect photos unless absolutely necessary
- do not expose children's reports publicly
- enforce role-based access
- Teacher can only access authorized students
- Parent/Guardian can only access authorized child
- Child cannot access private teacher/parent analytics
- protect stored progress data
- use secure authentication
- never expose API keys in frontend code

Store only the minimum information necessary for the feature.

18. PERFORMANCE
==================================================

Do not call Gemini after every single click.

Record activity locally/backend first.

Analyze in batches:

- after a zone completion
- after a session
- when opening the progress dashboard
- when a teacher/parent requests a report

Cache generated reports where appropriate.

Do not repeatedly send the entire child history to Gemini.

Send only the relevant summarized data.
