Create a polished, child-friendly **2D educational puzzle/maze game** based on **POCSO Act awareness and child safety**, designed for the Nyaya Nagri educational platform.

The game must feel like a REAL PLAYABLE PUZZLE GAME, NOT a quiz or static educational screen.

## GAME CONCEPT

The player controls a cute child-friendly cartoon character.

The objective is:

**START → SAFELY NAVIGATE THE PATH → END / SAFE ZONE**

The character must travel through a maze-like environment.

There should be multiple possible paths, but some paths contain **POCSO-related unsafe situations/obstacles**.

The player must identify the safe path and guide the character around dangerous/incorrect choices.

The game should teach:

**Recognize → Avoid → Choose Safe Action → Reach Safety**

Do NOT visually depict sexual abuse or explicit situations.

All POCSO-related situations must be represented through safe, symbolic, age-appropriate visual storytelling.

---

Use a colorful, polished children's educational adventure-game style.

Visual direction:

* Bright blue/purple sky
* Green grassy environment

* Trees

* Playground/school elements
* Rounded game UI
* Friendly cartoon characters

* Soft shadows
* Colorful but not overly saturated
* Premium educational-game quality

The overall feeling should be:

**Safe + Friendly + Adventure + Learning**

Avoid making the game dark, scary, violent, or disturbing.

# MAZE / PATH

Create a visually clear maze with approximately 4–6 possible paths.

Some paths should be safe.

Some paths should lead toward obstacles.

The player must decide which path to take.

Use:

* paths
* bridges
* intersections
* arrows
* checkpoints
* blocked routes

Do NOT make the maze impossibly complicated.

It should be understandable for children.

# POCSO-RELATED OBSTACLES

Place several obstacles throughout the maze.

Each obstacle represents an unsafe situation in a simple, non-graphic way.

Examples:

## OBSTACLE 1 — SECRET REQUEST

Show a phone/chat symbol with a speech bubble:

**“Don't tell anyone about this.”**

Place a red warning sign:

🚩 UNSAFE

The character must avoid this path.

Educational concept:

**Children should tell a trusted adult when someone asks them to keep an uncomfortable or unsafe secret.**

---

## OBSTACLE 2 — UNSAFE ONLINE CONTACT

Show a smartphone with an unknown person/message.

Message:

**“Send me your private photo.”**

Add:

🚫 DO NOT SHARE

The path should be visually blocked.

Do NOT show explicit imagery.

---

## OBSTACLE 3 — UNCOMFORTABLE SITUATION

Show a child looking uncomfortable while an adult/person is standing too close.

Use a visual boundary circle around the child.

Add:

**“Your body belongs to you.”**

and:

🛑 STOP

Keep the scene completely non-sexual and age-appropriate.

---

## OBSTACLE 4 — BRIBE / SECRET

Show an unknown person offering a gift box.

Speech bubble:

**“I'll give you a gift. Don't tell anyone.”**

Add:

🚩 RED FLAG

The player should understand that this is an unsafe situation.

---

## OBSTACLE 5 — TRUSTED ADULT

Instead of making every adult an obstacle, include a SAFE checkpoint.

Show:

👩 Parent / 👨 Teacher / 👩‍🏫 Trusted Adult

with:

**“You can talk to me.”**

This should be a GREEN safe route.

This is important so the game teaches children that trusted adults are a source of help.

# PATH COLOR LANGUAGE

Use subtle visual cues but do not make the answer immediately obvious.

Safe paths:

* soft green
* blue
* normal path

Unsafe paths:

* orange/red warning markers
* 🚩 symbols
* blocked sections

However, the player should still need to understand the situation.

Do not simply make the correct path green from the beginning.

# GAME MECHANIC

The player controls the character using:

* Arrow keys on desktop
* WASD on desktop
* Swipe/touch controls on mobile

The character moves through the maze.

When approaching an obstacle:

Pause the character.

Show a small situation card.

Example:

### 🚩 RED FLAG

**“Someone asks you to keep an uncomfortable secret.”**

Then provide two actions:

🛡️ **Tell a trusted adult**

or

🚫 **Keep it secret**

The player must choose the safe action.

Correct choice:

✓ Safe choice!

Character continues.

Wrong choice:

⚠️ Think again!

Character returns to the previous checkpoint.

IMPORTANT:

The game should NOT become a traditional quiz.

The situation card should appear as part of the maze gameplay and directly affect the character's movement.
