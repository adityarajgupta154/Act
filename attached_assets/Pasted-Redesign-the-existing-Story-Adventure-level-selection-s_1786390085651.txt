9. LOCKING SYSTEM
==================================================

Implement real progression logic.

Rule:

Level 1 is unlocked by default.

Level N+1 becomes unlocked ONLY when Level N is completed.

Example:

Level 1 completed
→ Level 2 unlock animation

Level 2 completed
→ Level 3 unlock animation

Level 3 completed
→ Level 4 unlock animation

etc.

Never allow users to directly open a locked level.

If a locked level is clicked:

"Pehele pichhla adventure complete karo! 🔒"

Do not navigate to the level.

==================================================
10. CANDY-CRUSH-STYLE UNLOCK ANIMATION
==================================================

When a level is completed, DO NOT immediately switch to the next level without feedback.

Create a polished unlock sequence:

1. Current level trophy gets a subtle glow.
2. Green checkmark appears.
3. Sparkles appear around the node.
4. Progress path lights up from the completed node toward the next node.
5. Next level node starts glowing.
6. Lock icon disappears.
7. Next level badge scales from ~0.8 to 1.0.
8. Small sparkle burst.
9. Show:

"New Adventure Unlocked! 🎉"

Then show the new level as active.

Animation should be smooth and short.

Approximately:
700ms–1500ms total.

Do NOT make the animation annoying or slow.
