## IMPLEMENTATION TASK — RIGHT TO CHILDHOOD DRAG & DROP GAME

Implement a new **fully playable drag-and-drop educational game** inside my existing **Nyaya Nagri** application.

The purpose of this feature is to address jury feedback that the project currently feels like a quiz/gamified quiz rather than a real game.

This feature MUST feel like an actual game because the core mechanic is:

**OBSERVE → DRAG → DROP → MATCH → FEEDBACK → SCORE → COMPLETE**

Do NOT implement this as a normal multiple-choice quiz.

---

# 1. CORE GAME CONCEPT

Game title:

**Right to Childhood**

Subtitle:

**Build a happy, safe and equal childhood!**

The game screen contains:

### TOP SECTION — 3 EMPTY TARGET SLOTS

There are exactly **3 rights**:

1. Right to Education
2. Right to Play
3. Right to Protection

Each right has an empty visual drop zone.

Example:

┌────────────────┐   ┌────────────────┐   ┌────────────────┐
│       1        │   │       2        │   │       3        │
│                │   │                │   │                │
│ Right to       │   │ Right to       │   │ Right to       │
│ Education      │   │ Play           │   │ Protection     │
│                │   │                │   │                │
│   DROP HERE    │   │   DROP HERE    │   │   DROP HERE    │
└────────────────┘   └────────────────┘   └────────────────┘

These slots must be actual drag-and-drop targets.

---

# 2. BOTTOM SECTION — 4 IMAGE OPTIONS

At the bottom, display exactly **4 illustrated scenario cards**.

There will always be:

### 3 CORRECT IMAGES

Example:

IMAGE 1:
A child studying in a classroom.

Correct destination:
→ Right to Education

IMAGE 2:
Children playing in a playground.

Correct destination:
→ Right to Play

IMAGE 3:
A child being cared for and protected by a trusted adult.

Correct destination:
→ Right to Protection

### 1 DISTRACTOR IMAGE

Example:

IMAGE 4:
A child doing labour instead of going to school.

This image does NOT belong in any of the three slots.

This is extremely important.

The fourth image should act as a **distractor**, forcing the player to understand the situation rather than simply matching everything.

---

# 3. DRAG & DROP BEHAVIOUR

The player must be able to:

1. Click/touch and hold an image.
2. Drag the image.
3. Move it over one of the three target slots.
4. Release it.
5. Game checks whether the placement is correct.

Support both:

* Mouse drag
* Touch drag

Do NOT rely only on HTML desktop drag behaviour.

If the existing project uses React, implement the interaction using the project's existing interaction/animation system.

If Framer Motion is already installed, prefer using it.

---

# 4. CORRECT DROP

If the image belongs to the selected right:

Example:

Child studying
→ dropped into
Right to Education

Then:

1. Target slot gets a green glow.
2. Image smoothly snaps into the slot.
3. Show animated ✓.
4. Play a small success animation.
5. Award points.

Example:

**+100 ⭐**

6. Lock the placed image so it cannot be dragged again.
7. Mark that target as completed.

Example visual:

✓ RIGHT TO EDUCATION
[child studying image]

Use a subtle celebration effect such as:

* small stars
* particles
* sparkle
* gentle scale animation

Do NOT use excessive confetti.

---

# 5. WRONG DROP

If a correct image is dragged to the wrong target:

Example:

Child playing
→ dropped into
Right to Education

Then:

1. Target briefly shakes.
2. Target gets a subtle red/orange warning state.
3. Show:

**"Not quite! Try another place."**

4. Image smoothly returns to its original position.
5. Do NOT remove the image.
6. Do NOT reduce the score heavily.
7. Allow the player to try again.

The game should be encouraging and child-friendly.

---

# 6. DISTRACTOR IMAGE BEHAVIOUR

The fourth image is intentionally NOT a correct answer.

Example:

Child labour image.

If the user tries to place it into ANY of the three slots:

Show:

**"This doesn't belong here."**

Then:

* Brief red/orange feedback
* Small shake
* Return image to bottom tray

The distractor must NEVER become locked into a target.

This is a critical part of the gameplay.

---

# 7. GAME COMPLETION

The game is complete ONLY when:

* Right to Education has the correct image

Show:

Show:

⭐⭐⭐

**300 Points**
