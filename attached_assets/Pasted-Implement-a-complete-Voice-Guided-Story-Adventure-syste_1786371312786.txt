Implement a complete Voice-Guided Story Adventure system for Nyaya Nagri.

IMPORTANT:
The target users are children around 8 years old.
Many children may not be able to comfortably read the story captions, questions, or answer options themselves.

Therefore, the existing AI Assistant must become a voice narrator and guide throughout the entire Story Adventure.

DO NOT redesign the existing Story Adventure UI.
DO NOT remove the existing images, captions, questions, options, navigation, AI assistant, or game functionality.

Only add a robust voice-guided interaction layer on top of the existing Story Adventure.

==================================================
CORE EXPERIENCE
==================================================

The AI Assistant should guide the child through every story slide using voice.

For EVERY story slide:

1. The slide opens.
2. AI Assistant automatically starts speaking.
3. First, read/explain the story content shown on that slide.
4. Read the caption naturally.
5. Explain the situation in simple child-friendly language.
6. If the slide contains a question:
   - First explain the question.
   - Then read Option 1.
   - Then read Option 2.
   - Then wait for the child to select an option.

The child should NOT have to read anything to understand the story.

==================================================
STORY SLIDE VOICE FLOW
==================================================

For slides 1–3 and other narrative slides:

Example:

Slide 1:
AI voice:

"Riya school se ghar wapas aa rahi hai.
Raste mein use ek chhota sa gaon dikhai deta hai,
jahan kuch bachche khel rahe hain.

Riya ek naye gaon ke raste se guzar rahi hai."

The exact caption/content already configured for the slide should be used.

IMPORTANT:
Do not invent a different story.
Use the existing story data/caption associated with the current slide.

The AI can make the wording slightly more natural for spoken narration, but must preserve the original meaning.

Then automatically continue normally when the child moves to the next slide.

==================================================
SLIDE TRANSITION
==================================================

When the child clicks:

Next

OR the story automatically moves to the next slide:

1. Stop any currently playing speech.
2. Wait a very short transition delay.
3. Load the new slide.
4. Start narration for the new slide automatically.

Never allow speech from the previous slide to continue into the next slide.

There must NEVER be two voice narrations playing simultaneously.

==================================================
QUESTION SLIDE FLOW
==================================================

When the story reaches the question slide:

DO NOT immediately start repeatedly saying the question.

Use this exact sequence:

STEP 1 — Explain the situation

AI:

"Riya ke saamne ab ek important decision hai.
Aman ko madad ki zaroorat hai.
Ab dekhte hain Riya kya faisla karti hai."

STEP 2 — Ask the question

AI:

"Riya ke paas ek decision tha —
kya woh Aman ki madad karegi?"

STEP 3 — Read the options

AI:

"Option one:
Chup chaap aage badh jao."

Short pause.

AI:

"Option two:
Aman ke liye help bulao."

Short pause.

STEP 4 — WAIT FOR USER

After both options are spoken:

Do NOT immediately repeat the question.

Wait for the child to select an answer.

==================================================
NO ANSWER REMINDER SYSTEM
==================================================

If the child does not select any answer after the initial question narration finishes,
the AI Assistant should gently remind them.

IMPORTANT:
Do NOT repeat the exact same sentence every time.

Use different child-friendly variations.

For example:

First reminder:

"Abhi tak koi option select nahi hua hai.
Aapko kaunsa answer sahi lagta hai?"

Second reminder:

"Riya ko ab ek choice karni hai.
Neeche diye gaye dono options mein se ek choose karo."

Third reminder:

"Chalo, Riya ki help karte hain.
Aapke hisaab se use kya karna chahiye?"

Fourth reminder:

"Ab aapki baari hai.
Kisi ek option par tap karke answer do."

Then continue using a pool of natural variations.

DO NOT use robotic repetition.

==================================================
REMINDER TIMING
==================================================

Do NOT speak every second continuously.

Use a sensible reminder interval.

Recommended:

Initial narration:
Question + options

Then wait:

~5–7 seconds

If no answer:
Reminder #1

Then wait:

~7–9 seconds

If no answer:
Reminder #2

Then wait:

~9–12 seconds

If no answer:
Reminder #3

Then continue with longer intervals.

IMPORTANT:
Never create an infinite aggressive speech loop.

The child should feel guided, not pressured.

==================================================
STOP REPEATING IMMEDIATELY
==================================================

The moment the user clicks ANY answer:

1. Immediately stop current AI speech.
2. Cancel all pending reminder timers.
3. Cancel the reminder queue.
4. Do not speak another reminder.
5. Process the selected answer normally.

This is extremely important.

There must never be a situation where:

Child clicks answer
+
AI continues saying:
"You haven't selected an option yet..."

==================================================
WRONG ANSWER FLOW
==================================================

If the selected answer is incorrect:

1. Stop all narration.
2. Highlight the selected answer using the existing wrong-answer UI.
3. Show the existing explanation/feedback.
4. AI Assistant should read the feedback aloud.

Example:

"Ye answer best choice nahi tha.

Aman ko help ki zaroorat thi.
Aise situation mein kisi trusted adult ya doctor se help lena important hai.

Chalo, ek baar phir try karte hain."

Then say:

"Try Again button par tap karke dobara answer choose karo."

Do NOT automatically advance.

The child must choose again.

==================================================
CORRECT ANSWER FLOW
==================================================

If the selected answer is correct:

1. Stop all reminder timers.
2. Stop current speech.
3. Highlight the correct option.
4. Show the existing success feedback.
5. AI Assistant reads the explanation.

Example:

"Bahut achha!

Aman ke liye help bulana sahi decision tha.
Jab kisi bachche ko zaroori madad ki zaroorat ho,
toh trusted adult ya doctor se help lena important hai."

Then:

"Ab Next par tap karke story continue karo."

Only after the correct answer should the Next action become available.

==================================================
EVERY SLIDE MUST BE DATA-DRIVEN
==================================================

Do NOT hard-code separate voice logic for only Level 1.

Create a reusable story narration system.

Each story slide should be able to contain:

{
  id,
  image,
  caption,
  narration,
  question,
  options,
  correctAnswer,
  explanation
}

If narration is not explicitly provided,
generate narration from the existing caption/story content.

IMPORTANT:
Never invent new story facts that contradict the configured story.

==================================================
CHILD-FRIENDLY LANGUAGE
==================================================

Voice should sound like a friendly educational guide.

Use:
- Simple Hindi/Hinglish
- Short sentences
- Natural pauses
- Clear pronunciation
- Warm tone
- Encouraging language

Avoid:
- Complicated legal terminology
- Long sentences
- Robotic speech
- Overly formal language

The AI should feel like a friendly guide helping a child play the game.

SPEAKING
- subtle animation

LISTENING / WAITING
- calm idle animation

==================================================
FAST RESPONSE / LOW LATENCY
==================================================

The voice system must feel fast.

IMPORTANT:
Do NOT call the AI model for every tiny sentence.

Do NOT generate a new Gemini response for every reminder.

Prefer:

1. Prepare narration from the story data.
2. Cache/generated voice content.
3. Play the audio immediately.
4. Preload the next slide's narration where possible.

For fixed story content, narration can be generated ahead of time.

Question and option narration should also be prepared before the child reaches the question.

The interaction must NOT feel laggy.

==================================================
BACK BUTTON
==================================================

If the child clicks Back:

1. Stop voice immediately.
2. Cancel reminders.
3. Reset narration state.
4. Go to previous slide.
5. Start narration for the previous slide.

Never let the previous slide's voice continue.

==================================================
NEXT BUTTON
==================================================

When Next is clicked:

1. Stop current voice.
2. Cancel reminders.
3. Move to next slide.
4. Reset answer state.
5. Automatically narrate the new slide.

==================================================
IMPORTANT QUESTION RULE
==================================================

For every question slide, ALWAYS follow this exact order:

1. Explain situation
2. Read question
3. Read option 1
4. Read option 2
5. Wait for answer
6. If no answer → gentle reminder
7. Continue reminders with varied wording
8. User selects answer → STOP reminders immediately
9. Evaluate answer
10. Read feedback
11. Correct → Next
12. Wrong → Try Again

Never change this sequence.
