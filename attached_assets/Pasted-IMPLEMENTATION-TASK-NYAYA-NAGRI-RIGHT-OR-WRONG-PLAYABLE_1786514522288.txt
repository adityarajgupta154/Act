IMPLEMENTATION TASK — NYAYA NAGRI: “RIGHT OR WRONG?” PLAYABLE MINI-GAME

I want to add a new interactive mini-game to my existing Nyaya Nagri project.

IMPORTANT CONTEXT:
The jury feedback was:
“The project has gamification, but it is basically just a quiz. There is no actual game.”

So this feature must feel like a REAL SIMPLE GAME, not another quiz screen.

The game should teach children about their fundamental rights / Right to Childhood through visual decision-making.

CORE GAME CONCEPT:
Show TWO visual situations/scenes side-by-side.

The player must choose:
“Which one shows the RIGHT thing?”

Example:
LEFT IMAGE:
Children studying in a classroom → RIGHT

RIGHT IMAGE:
A child working in a dangerous factory → WRONG

The player clicks/taps one of the two scenes.

The game immediately gives feedback:
- Correct → positive animation, points/reward, cheerful feedback
- Wrong → gentle correction, explanation, and opportunity to continue
- Never make the child feel punished or embarrassed.

--------------------------------------------------
1. GAME SCREEN
--------------------------------------------------

Create a dedicated game screen called:

“Right or Wrong?”

Top section:
- Score
- Progress indicator
- Sound toggle
- Home/Back button

Main heading:

“Which one is RIGHT?”

Subheading:

“Choose the picture that shows a right every child has.”

Main game area:
A large rounded game board/card.

Inside it:

             [ IMAGE A ]     OR     [ IMAGE B ]

Each image must be a large clickable game card.

Do NOT make them look like normal multiple-choice buttons.

They should feel like two objects/scenes inside a game.

Each card should contain:
- Large illustration
- Short scenario title
- Optional small description

Example:

IMAGE A
Children Learning
“Every child has the right to education.”

IMAGE B
Child Labour
“A child is forced to work.”

--------------------------------------------------
2. ACTUAL GAME INTERACTION
--------------------------------------------------

The interaction is the most important part.

When the user hovers over a card:
- Slight scale-up
- Small lift animation
- Soft shadow
- Cursor becomes pointer
- Image/card gets a subtle highlight

When the user clicks a card:

CORRECT:
- Card gets a green border
- Large animated check mark appears
- Small celebration particles/confetti
- Score increases
- Show “Great choice!”
- Show the related right in simple language
- Play a short positive animation/sound if sound is enabled

WRONG:
- Card briefly shakes
- Card gets a red/orange border
- Show a gentle “Try again!” feedback
- Explain why this situation is not protecting the child’s right
- Do NOT immediately end the game
- Allow the player to select the other card

After the correct answer:
- Disable both cards temporarily
- Show feedback for around 1–1.5 seconds
- Then automatically transition to the next round.

This makes it an actual GAME LOOP rather than a static quiz.
